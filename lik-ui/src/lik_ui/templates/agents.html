Before you start

This service runs on the Claude Managed Agents platform, which is currently in beta. Data you send here is not covered by Zero Data Retention, so your conversations are retained by the platform. (For more details, see claude-managed-agents.md)

As a mitigation, chat sessions are automatically deleted after the auto-delete date, defaults to 7 days from creation. You can adjust the auto-delete date for each session and manually delete sessions at any time.
